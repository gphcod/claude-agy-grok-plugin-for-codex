## How it was run

- Repositories: `cx/repos/<p>-ask` (base commit, then `sumFirst: include n` committing the off-by-one `i <= n`), `cx/repos/<p>-review` (branch `feature` with that commit, plus the uncommitted `age >= 18` → `age > 18`), `cx/repos/{fanout,ws,setup,hostint1,hostint2}`; built by `cx/scripts/build-repos.sh`. Offline root and merge fixtures are built inline (see `offline/out/commit-*.txt`).
- Live cells: `cx/scripts/cx.sh <cell> <cwd> <sandbox> <prompt> [thread]`, which runs `clean.sh codex exec --json -s <sandbox> -c model_reasoning_effort=medium "<prompt>" </dev/null` (or `codex exec resume --json -c sandbox_mode="<sandbox>" … <thread> "<prompt>"` for later turns of the same session; `clean.sh` removes the parent host's `CLAUDE*`/`CODEX*`/`COUNCIL*` variables). Prompts are natural requests naming `$council`, the provider and "effort low"; they are saved as `ev/<cell>.prompt`. Sessions: ask/reply/wait/task per provider (5 turns), reviews per provider (3–5 turns, including the workspace-write replay), setup (3 turns), fan-out (2), workspace-write (1), host integration (2).
- Offline cells: `cx/scripts/off.sh <scenario> <council args…>` runs the installed `council.mjs` through `clean.sh` with the fakes and a scratch state root.
- Zero-submission check for row 39: `grep -rl <session id> ~/.codex/council` and the job sessions in `meta.json` (none); the state root is checked first, before any probe or reservation.
- Cost: 32 council provider submissions (claude 10, gemini 10, grok 12, including `setup --live`) plus one old-plugin Grok call; reported provider cost claude $0.576, grok $0.231 (+ $0.02 old plugin), gemini not reported by agy. Codex: 11 sessions, 34 turns, 7.43 M input tokens (6.92 M cached), 29,861 output tokens.
